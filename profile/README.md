# Mixcraft — home studio lanes for loops you own

Mixcraft keeps one named board on the desk: the live multitrack lanes, the loop in front of you, and a short note the next home session can read. Extra projects wait for their own title.

## Session Card

| Slice | What you do in Mixcraft | What remains |
|-------|------------------------|--------------|
| Arrival | Open Mixcraft and name today's home studio | A titled music project |
| Focus | Keep only live lanes on the Mixcraft board | A short loop list |
| Check | Read Mixcraft multitrack before a large arrange | A confirmed lane set |
| Handoff | Mark finished loops inside Mixcraft | A note for the next visit |

## How Mixcraft Sits

Mixcraft does not replace the loop browser, the unnamed take folder, or the DAW you already keep for other jobs. It sits beside them as a named home studio for one job: which multitrack is live, which loops still belong in the music project, and what the next person should read.

A first visit should be one short loop lane, then the same Mixcraft home studio the next day. That is enough to see if the named music project holds.

## Traffic Light

| Signal | On the Mixcraft board | What you do |
|--------|----------------------|-------------|
| Green | Named project, short live loop list | Continue the same multitrack |
| Amber | Two songs mixed in one music project | Split the lanes before you arrange |
| Red | No title, no note, unnamed takes everywhere | Stop and name the project first |
| Clear | Handoff written, live loops few | Close Mixcraft and leave the home studio |

## Open Order

1. Open the last Mixcraft music project, not a new empty home studio.
2. Read the loop lanes and the last handoff.
3. Finish one visible multitrack step inside Mixcraft.
4. Write what changed, then close with fewer unnamed takes than you found.
5. If the project feels crowded, drop anything that belongs to a different Mixcraft song.

## After a Week

A week in Mixcraft is not a larger pile of unnamed takes. It is the same title, a shorter live loop list, and a note that still makes sense on the next home session. Take finished loops off the live set so the next visit starts on the music project that is still open.

Other programs stay where they are. Mixcraft only keeps the path back: project name, multitrack lanes, loops, handoff.

## Sign-off

- [ ] The Mixcraft workspace name is short enough to scan
- [ ] Only live loops sit on the lanes
- [ ] A second person can read the project handoff

## Field Note

Mixcraft is easier to trust when the home studio stays smaller than the unnamed take pile it came from. Name the project, keep the live lanes, finish one visible loop, and write what changed.
